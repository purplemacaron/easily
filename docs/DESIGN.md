# Easily — 디자인 시스템

> 한 문장: **종이 위의 잉크.** 흰 바탕, 검은 글자, 얇은 선, 색은 "상태"를 말할 때만.
> 기본 테마는 **라이트**. 다크는 같은 토큰의 반전으로만 제공한다.

## 1. 원칙

1. **기능이 많을수록 화면은 조용해야 한다.** 기능은 커맨드 팔레트(⌘K / Ctrl+K)와 사이드바 목록으로 찾게 하고, 화면에 버튼을 늘어놓지 않는다.
2. **밀도는 높게, 장식은 0.** Linear·Things·macOS 설정 앱 수준의 정보 밀도. 카드 그림자, 그라데이션, 글래스모피즘 없음.
3. **선(1px)으로 구획한다.** 면 색 차이는 최대 2단계(`--bg`, `--bg-sunken`).
4. **색은 의미다.** 강조색(`--accent`)은 "지금 실행 중 / 주목" 단 하나의 의미. 성공·경고·오류는 작은 점·텍스트로만.
5. **타이포가 위계를 만든다.** 굵기 400/500/600 세 개, 크기 6단계 이내.

## 2. AI 슬롭 금지 목록 (리뷰 시 하나라도 있으면 반려)

- 보라/파랑 그라데이션, 무지개 테두리, 빛나는(glow) 효과, 블러 배경
- ✨🚀🔥 등 이모지를 아이콘 대신 쓰기, "Supercharge / Unleash / Revolutionize / 혁신적인" 문구
- 둥근 모서리 16px 이상의 둥실둥실 카드, 큰 드롭섀도
- 의미 없는 3열 "기능 카드" 그리드 + 동일 크기 아이콘 원
- 히어로에 추상 3D 블롭/구체/메시 그라데이션
- 모든 버튼을 accent 색으로 칠하기 (primary는 **검정** 버튼)
- 기본 shadcn/Tailwind 팔레트 그대로 쓰기 (slate-500, indigo-600 …)
- 스켈레톤 로더 남발, 과한 마이크로 애니메이션 (전환은 120ms 이하, 이징 하나)

## 3. 토큰 (단일 출처: `apps/desktop/src/renderer/src/styles/tokens.css`, 사이트는 `site/styles.css` 상단에 동일 값 복제)

### 색 — 라이트 (기본)
| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg` | `#FFFFFF` | 기본 면 |
| `--bg-sunken` | `#F7F7F5` | 사이드바, 코드, 입력창 배경 |
| `--bg-hover` | `#F0F0EE` | hover |
| `--line` | `#E8E8E5` | 1px 구분선 |
| `--line-strong` | `#D4D4D0` | 입력 테두리, 포커스 전 |
| `--ink` | `#111111` | 본문, primary 버튼 |
| `--ink-2` | `#5C5C58` | 보조 텍스트 |
| `--ink-3` | `#9A9A95` | 힌트, 비활성 |
| `--accent` | `#2B9AF3` (하늘색) | 포인트 컬러: 실행 중 상태, 선택됨, 포커스 링, 링크 hover (면적 2% 이하) |
| `--ok` | `#1F8A4C` | 성공 점/텍스트 |
| `--warn` | `#B26B00` | 경고 |
| `--err` | `#D12C2C` | 오류 |

### 색 — 다크 (선택)
`--bg #0F0F0E`, `--bg-sunken #171716`, `--bg-hover #1F1F1D`, `--line #262624`, `--line-strong #34342F`,
`--ink #EDEDEA`, `--ink-2 #A3A39E`, `--ink-3 #6B6B66`, `--accent #5CB4F7` (나머지 동일 계열 밝기 보정).

### 로고
- 로고는 **텍스트 워드마크 "Easily"** 하나. Pretendard 600, 자간 -0.02em. 심볼·아이콘 없음.
- 파비콘/앱 아이콘만 예외: 하늘색 둥근 사각형 위 흰색 기하학 "E" (`site/favicon.svg`).

### 타이포
- UI/본문: **Pretendard Variable** (한글·영문 동시 균형). 폰트 파일은 앱에 번들, 사이트는 jsDelivr CDN.
- 코드·숫자·단축키: **JetBrains Mono**.
- 스케일(px): `11 / 12 / 13(기본 UI) / 15(본문) / 20 / 28`. 사이트 히어로만 `56–72`.
- 자간: 20px 이상 제목은 `-0.02em`. 숫자는 `font-variant-numeric: tabular-nums`.

### 간격·형태
- 4px 그리드: `4 8 12 16 24 32 48 64`.
- 반경: `--r-sm 4px`(뱃지·kbd), `--r 6px`(버튼·입력), `--r-lg 10px`(모달·팝오버). 그 이상 금지.
- 그림자: 팝오버/모달만 `0 8px 24px rgba(0,0,0,.08), 0 0 0 1px var(--line)`.
- 아이콘: **Lucide** 1.5px 스트로크, 16px(UI)/14px(밀집 목록). 채워진 아이콘 금지.

## 4. 레이아웃 — 데스크톱 앱

```
┌──────────┬────────────────────────────────────────┬─────────────┐
│ Sidebar  │  Main (세션 / 선택한 화면)               │ Inspector   │
│ 232px    │  최대 본문 폭 760px, 가운데 정렬           │ 320px (토글)│
│          │                                        │             │
│ ⌕ 검색   │  메시지 스트림                           │ 컨텍스트 사용량│
│ 세션      │  ─ 툴 호출은 한 줄 요약 + 펼치기          │ 비용·토큰    │
│ 스케줄    │  ─ diff는 인라인, 승인 버튼은 우측        │ 활성 MCP     │
│ 워크플로  │                                        │ 메모리 회수   │
│ MCP      │                                        │ 체크포인트    │
│ 스킬      │ ┌────────────────────────────────────┐ │             │
│ 메모리    │ │ 입력창 · / 명령 · @ 파일 · 모드 · 모델│ │             │
│ 개선안    │ └────────────────────────────────────┘ │             │
│ ──────── │                                        │             │
│ 설정      │                                        │             │
└──────────┴────────────────────────────────────────┴─────────────┘
타이틀바: 커스텀(높이 40), 좌측 세션 제목, 우측 상태 점 + 비용
```

- 상태 표시는 **6px 원 + 레이블** 하나로 통일 (`● 실행 중` 는 accent, `● 대기` 는 ink-3).
- 빈 상태(empty state)는 일러스트 대신 **한 줄 설명 + 단축키 2–3개**.
- 모든 화면은 키보드만으로 조작 가능. 단축키는 우측에 `kbd`로 표기.

## 5. 웹사이트 (GitHub Pages)

- 구조: 히어로(한 문장 + 다운로드) → 핵심 5개(이름만) → 모델 로고 → 기능 목록(이름만) → 다운로드 → 푸터.
- **설명문 금지.** 섹션마다 제목 한 줄과 목록뿐. 부연 문단, 가짜 앱 스크린샷, 통계 숫자 줄, 가짜 코드 블록, 번호 매긴 챕터 라벨 금지.
- "기능이 많다"는 사실은 **목록의 길이 자체**로 보여준다.
- provider 로고는 회색조, hover 시 원색. 높이 18px.
- 폭 1120px 컨테이너, 모바일 16px 거터, 가로 스크롤 금지.
